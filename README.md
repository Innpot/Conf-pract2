# Практическая работа № 2 — вариант 20

Визуализатор графа зависимостей пакетов Ubuntu. Этап 1: проверка INI и
вывод параметров в формате ключ=значение. Нужен Python 3.10+, сборки и
сторонних библиотек нет.

~~~sh
python -m src.main --config examples/ubuntu.ini
python -m unittest discover -s tests -v
~~~

Для проверки ошибок измените один из ключей INI. Варианты неверных
значений для всех пяти ключей проверяет tests/test_config.py.
